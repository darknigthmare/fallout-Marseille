FALLOUT MARSEILLE — MISTRAL v0.50

POUR JOUER : téléchargez FALLOUT_MISTRAL_v0.50_JEU_COMPLET.zip, extrayez-le
puis lancez LANCER_APP_WINDOWS.bat, LANCER_APP_LINUX.sh ou LANCER_APP_MAC.command.
Python 3 est requis. Les cartes et reliefs sont déjà extraits.

PROJET COMPLET : le ZIP de 272,727,017 octets est livré en 5 parties.
Téléchargez toutes les parties .zip.001, .zip.002, etc., ARCHIVE_PARTS.json,
RECONSTRUIRE_ARCHIVE.py et le lanceur adapté dans un même dossier.
Windows : RECONSTRUIRE_ARCHIVE_WINDOWS.bat ; Linux/macOS : python3 RECONSTRUIRE_ARCHIVE.py
Le script contrôle chaque partie, puis le SHA-256 et le CRC du ZIP reconstitué.
Il ne télécharge rien et ne remplace pas un ZIP différent déjà présent.
Ne tentez pas d’extraire les parties séparément. Si Drive les enveloppe dans
un autre ZIP, extrayez d’abord cette enveloppe.

Le projet complet contient le jeu, les données extraites, les 24 archives
géographiques d’origine, les sources, les tests et l’historique conservé.
Consultez le rapport visuel v0.50 et docs/KNOWN_LIMITATIONS_V0.50.md.
