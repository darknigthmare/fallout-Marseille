# Notes de publication v0.40

La v0.40 termine la première certification de deux traversées longues fondées sur le cache OpenStreetMap : Aubagne–Marseille et Aubagne–La Ciotat. Elle ajoute un roadbook jouable, le préchargement de corridor, la surveillance des téléportations, le recollage conservateur des bâtiments cadastraux et le lissage des transitions de relief.

Les preuves sont embarquées dans le HTML pour que l’absence de réseau ne supprime pas les trajets certifiés. Le relais cloud reste disponible en lecture seule et son bucket est privé.
