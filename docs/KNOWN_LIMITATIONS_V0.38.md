# Limites connues v0.38

- Relief numérique officiel : 0/8.
- Pack PBF non incorporé au ZIP compact.
- Le cache complet ne prouve pas que chaque bâtiment divisé a été fusionné.
- L'audit local complet nécessite l'installation des fichiers.
- Les raccords de routes doivent être audités sur le pack installé.
- Les portes réelles des intérieurs ne sont pas toutes raccordées.
- Les longues traversées humaines ne sont pas encore certifiées.
- Les modèles et le rendu restent procéduraux.
