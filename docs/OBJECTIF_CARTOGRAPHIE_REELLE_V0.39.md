# Objectif cartographique après v0.39

## Acquis
- 5 884/5 884 coordonnées vectorielles traitées dans le cache territorial ;
- 8/8 macro-régions dotées d’une grille RGE ALTI échantillonnée ;
- 174 944 altitudes valides et 32 424 cellules NoData ;
- cache privé, installateurs et auditeurs ;
- moteur terrain pack → IndexedDB → cloud ;
- affichage Pip-Boy et preuves de source.

## Prochaines priorités bloquantes
1. installer localement les 5 884 coordonnées et les huit reliefs ;
2. auditer tous les raccords routiers avec voisins présents ;
3. assembler les empreintes cadastrales divisées aux frontières ;
4. contrôler le littoral de manière continue ;
5. raccorder les intérieurs à leurs portes réelles ;
6. mesurer les performances du pack complet ;
7. parcourir Aubagne–Marseille et Aubagne–La Ciotat sans rupture ;
8. augmenter ensuite la densité altimétrique seulement si les budgets mémoire et rendu le permettent.
