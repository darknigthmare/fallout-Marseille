# Limites connues v0.41

- Le ZIP jeu reste compact et n’embarque pas le pack territorial lourd.
- Le runner utilisé pour cette livraison ne résout pas les domaines externes ; l’installation complète n’y a pas été exécutée.
- Les performances affichées dans les deux captures de présentation du rapport sont des données injectées uniquement pour valider la mise en page.
- Le benchmark réel dépend du disque, du processeur, de Python et de la mémoire de la machine cible.
- La disponibilité du pack ne remplace pas une traversée humaine de chaque route, tunnel, escalier, portail ou littoral.
- Le niveau z14 généralise certains détails routiers ; le cadastre z16 ne contient pas tous les objets urbains.
