# Development roadmap — skills-driven

P0: Validate real-world Marseille terrain, buildings, roads and seamless streaming. Preserve existing verified geography and fix reproducible edge mismatches first.
P1: Verify exterior loading/cancellation, physical collisions and geographic provenance.
P2: Stabilize camera, FPS HUD, controller input, UI safe areas, save compatibility and POI fast travel.
P3: Expand the vault prologue and French/Mediterranean Fallout-inspired factions, enemies, settlements, quests and branching dialogue as authored fictional overlays.
P4: Profile representative scenes; optimize measured CPU/GPU bottlenecks, memory budgets and streaming latency.
P5: Full playtesting, accessibility, licensing audit, distribution packaging and release readiness.

For each milestone: audit existing code, choose relevant upstream skill, implement a narrow vertical slice, run automated and in-game tests, capture real screenshots, then open a reviewable PR. Completion is evidence-based, not a percentage estimate.
