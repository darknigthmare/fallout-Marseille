# Notes de publication — v0.36 Territoire réel

## Nouveautés

- streaming vectoriel officiel sur huit macro-régions ;
- 367 tuiles OSM z14 et 5 517 tuiles cadastrales z16 dans le manifeste ;
- relais Supabase authentifié et borné ;
- installateur complet reprenable ;
- cache IndexedDB ;
- transitions automatiques entre macro-régions ;
- ajout d’Étoile et Sainte-Baume ;
- Pip-Boy, statut, HUD et crédits cartographiques ;
- outils de terrain et d’audit.

## Compatibilité

Toutes les couches produit de la v0.35 sont conservées. Les sauvegardes v0.35 restent migrables.

## Limite critique

Aucun MNT numérique officiel n’est inclus. Le ZIP ne contient pas le pack complet de PBF ; il faut streamer ou lancer l’installateur.
