# Commandes v0.50

- ZQSD / WASD : déplacement ; souris : regarder ; clic gauche : tirer.
- N : lancer une grenade à fragmentation possédée ; le bouton Grenade du HUD reste utilisable au tactile.
- E : interagir, ouvrir ou fermer une porte intérieure compatible ; Maj : courir ; Espace : sauter ; Ctrl : s’accroupir.
- R : recharger ; H : soin général ; C dans le monde : première/troisième personne.
- Tab : ouvrir/ranger le Pip-Boy. U : ouvrir directement STAT → ARMURE.
- L : lampe. I : sac. T : panneau de terrain. M : plan local.
- V : V.A.T.S. ; sélectionner un membre sur le modèle ou son étiquette, E ajoute, C réserve un critique, Espace exécute, V/Échap annule.
- Dans le Pip-Boy : Q/E changent de mode, A/D de rubrique, flèches sélectionnent les lignes. Les champs de texte capturent leurs propres touches.

Armure assistée : équiper la tenue, insérer un cœur neuf ou entamé, puis activer les moteurs. Couper avant de changer de tenue, éjecter une cellule ou travailler à l’établi. L’entretien par pièce nécessite une position sûre et un établi proche.

Le bouton HUD de charge ouvre le même diagnostic. Les six boutons sous le schéma restent utilisables au tactile. L’écran défile pour atteindre les devis et les modifications.

La partie de démonstration est séparée, non un saut imposé dans la campagne. Le test du portillon peut toujours se terminer avec la manivelle.
