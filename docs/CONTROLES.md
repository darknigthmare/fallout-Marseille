# Commandes v0.50 — 28 octobre 2026

- ZQSD / WASD : déplacement ; souris : regarder ; clic gauche : tirer.
- X maintenu, clic droit avec le pointeur capturé ou bouton Visée maintenu : présenter l’arme FPS dans l’axe du viseur. Le maintien n’ajoute pas de bonus de précision. Le relâchement, une interface, une perte de focus, le rechargement ou un changement d’arme/scène libèrent la visée.
- N : lancer une grenade à fragmentation possédée ; le bouton Grenade du HUD reste utilisable au tactile.
- P : poser une mine à fragmentation possédée sur un support libre et admissible devant le personnage. E à portée la désamorce et la récupère, y compris pendant l’avertissement.
- E : interagir, ouvrir ou fermer une porte intérieure compatible, utiliser un lit, une cuisine ou un établi admissible en regardant sa surface. Les choix de service vérifient leurs fournitures et leur contexte avant paiement.
- Maj : courir ; Espace : sauter ; Ctrl : s’accroupir.
- R : recharger ; H : soin général ; C dans le monde : première/troisième personne.
- Tab : ouvrir/ranger le Pip-Boy. U : ouvrir directement STAT → ARMURE.
- L : lampe. I : sac. T : panneau de terrain. M : plan local.
- V : V.A.T.S. ; sélectionner un membre sur le modèle ou son étiquette, E ajoute, C réserve un critique, Espace exécute, V/Échap annule.
- Dans le Pip-Boy : Q/E changent de mode, A/D de rubrique, flèches sélectionnent les lignes. Les champs de texte capturent leurs propres touches.

Le bouton **Suivi** masque ou affiche le suivi de quête ; **Options → Affichage en jeu** propose le HUD compact. Les préférences restent dans le navigateur. Les options de réduction des mouvements et flashes s’appliquent aux mains et à l’arme FPS. La présentation stylisée couvre neuf familles et conserve la direction de tir, les dégâts et les distances du jeu. [Vue FPS](VUE_FPS.md) · [HUD](HUD_FPS.md).

Les mines ont une rubrique **INV → MINES**. Les huit dossiers de continuité sont dans **DATA → RELAIS ET DOSSIERS** ; les contacts concernés les proposent aussi par les dialogues normaux. [Mines](MINES_A_FRAGMENTATION.md) · [Lore](LORE_CONTINUITE.md) · [Services intérieurs](INTERIEURS_USAGES.md).

Armure assistée : équiper la tenue, insérer un cœur neuf ou entamé, puis activer les moteurs. Couper avant de changer de tenue, éjecter une cellule ou travailler à l’établi. L’entretien par pièce nécessite une position sûre et un établi proche.

Le bouton HUD de charge ouvre le même diagnostic. Les six boutons sous le schéma restent utilisables au tactile. L’écran défile pour atteindre les devis et les modifications. Les essais tactiles et Gamepad émulés ne certifient pas un appareil physique.

La partie de démonstration est séparée de la campagne. Le test du portillon peut toujours se terminer avec la manivelle.
