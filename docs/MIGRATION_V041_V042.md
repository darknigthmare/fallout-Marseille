# Migration v0.41 → v0.42

La v0.42 ajoute `state.v042` : découvertes, sécurisations, sites visités, contrats, élites, boss, repère actif, retour d’instance et progression régionale.

Une sauvegarde v0.41 reçoit un état vide sans site découvert ni récompense gratuite. Le catalogue lui-même est déterministe et n’est pas copié dans la sauvegarde. Les clés v0.41 et antérieures restent des sources de migration.
