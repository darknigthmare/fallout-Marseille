La préparation initiale de l’atlas communal peut prendre plusieurs minutes.

1. Extraire entièrement l’archive avant de lancer le jeu.
2. Python 3 doit être installé.
3. Windows : LANCER_APP_WINDOWS.bat
   Linux : bash LANCER_APP_LINUX.sh
   macOS : bash LANCER_APP_MAC.command
4. Garder le serveur ouvert pendant la partie.

La fenêtre du navigateur utilise http://127.0.0.1:8765/index.html.
Depuis GitHub, le premier lancement prépare les cartes fournies hors réseau.
Dans l’archive JEU_COMPLET, les données sont déjà extraites.
